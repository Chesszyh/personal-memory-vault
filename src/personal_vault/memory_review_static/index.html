REVIEW GUIDE

接受还是拒绝？

接受

  • 确实是你本人直接表达，而不是引用、例子或转述。
  • 未来回答仍可能用得上，且表述脱离原会话也能理解。
  • 一条候选只保留一个事实、偏好、边界或仍有效计划。
  • 必要时先编辑，再接受；原始消息会继续保留作证据。

拒绝

  • 只是单次任务指令，如“不要解释，直接改这个文件”。
  • 正则误命中、引用他人的话、问题假设或提示词模板。
  • 已经过期、已经完成、被后续陈述推翻，或并非关于你。
  • 原话混合很多内容，无法提炼成一条准确记忆。

暂缓

  • 需要更多上下文才能判断。
  • 与另一条候选可能冲突，但尚未决定当前状态。
  • 时间敏感计划的有效性需要你稍后确认。

四种候选

身份
姓名、职业、专业等相对稳定资料。
偏好
语言、格式、工具和协作风格。
边界
跨会话也应遵守的“不要/禁止/无需”。
计划
正在进行或准备做的事情，最容易过期。
