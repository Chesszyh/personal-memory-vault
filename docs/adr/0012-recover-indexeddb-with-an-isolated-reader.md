# Recover IndexedDB with an isolated archive-only reader

The frozen extension database combines Chromium IndexedDB LevelDB records with external Blink/V8 structured-clone blobs, so generic LevelDB iteration cannot be trusted to recover it completely. Recovery will use a purpose-built archive-only MV3 extension in a fresh temporary Chrome profile, operating only on a Recovery Working Copy. The extension has no site permissions, background worker, content scripts, synchronization, or network code; it refuses to create or upgrade a missing database and exports every store through read-only cursors. Only that temporary Chrome process receives an isolated network namespace. The host, other browsers, and unrelated work remain online. Neither the historical extension, the realtime-only extension, nor ExtensionStorage is loaded.
