# Allow task-scoped cloud processing of the full corpus

The vault is not constrained to local-only analysis: the user may deliberately send complete raw history and attachments to ChatGPT or another cloud model when the expected benefit justifies it. Authorization binds a provider, purpose, and input set; that Cloud Processing Task may then run in automatic batches, while a new provider, purpose, or source requires new authorization. Secrets remain excluded unless individually released, and offline preservation and reproducibility never depend on a provider.
