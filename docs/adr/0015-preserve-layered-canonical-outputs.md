# Preserve layered canonical outputs without synthesizing an official export

The archive will retain immutable source captures, source-preserving decoded NDJSON, a rebuildable canonical SQLite database with FTS5, and Content-addressed Assets. Unknown fields and complete raw payloads remain available with Provenance. Official exports and extension observations are associated in canonical records but never rewritten into a file that claims to be an official OpenAI export. Any provider-shaped compatibility output is labeled as a Derived Provider View.
